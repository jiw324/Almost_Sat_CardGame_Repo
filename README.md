# Almost_Sat_CardGame_Repo

Unity project using Unity version (6000.1.14f1)


9/8/25 - Adrian M:
Created sample scene with drag and drop logic for cards.
Created basic logic for card data as well as handling spawning of cards.

To make new cards for testing, create a new asset (Card) from the context menu and assign the appropriate values.
Expand the HandManager to contain the new card.
